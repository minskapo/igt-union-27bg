# 2027 임금·단체교섭 요구안 해설 · 연구소 공유본

녹색전환연구소노동조합이 연구소(사측)와 함께 보기 위해 만든 요구안 해설 페이지입니다. 조합원 공유본(`imdanhyup-2027`)과 저장소, 주소, 의견 저장소를 모두 분리했습니다.

## 구성

- `index.html`: 배포되는 페이지(빌드 결과물)입니다. GitHub Pages가 이 파일을 그대로 제공합니다.
- `src/gdoc.html`: 구글 문서 「녹조_2027년 임금·단체교섭 요구안 해설_사측공유본」의 HTML 내보내기입니다.
- `src/current-rules.html`: 현행 규정 7종(기본협약, 2026년 임금협약, 취업규칙, 운영실무규정, 고충처리규정, 회계실무규정, 퇴직연금규약)의 원문입니다.
- `tools/parse_doc.py`: 구글 문서를 조문 단위 데이터로 바꿉니다.
- `tools/build.py`: 데이터와 `tools/style.css`, `tools/app.js`를 합쳐 `index.html`을 만듭니다.

## 다시 만들기

구글 문서를 고친 뒤에는 문서를 HTML로 내보내 `src/gdoc.html`을 바꾸고 아래 명령을 실행합니다. 입장 암호는 환경변수로 넘기며, 페이지에는 SHA-256 해시만 들어갑니다.

```sh
pip install beautifulsoup4 lxml
GATE_PASSWORD='전달할 암호' python3 tools/build.py
```

## 의견 저장소

Supabase 프로젝트 `imdanhyup-2027-share`(서울 리전)의 `comments` 테이블을 씁니다.

- 누구나 읽고 쓸 수 있지만, 삭제는 의견을 남긴 브라우저만 할 수 있습니다. 등록할 때 브라우저에 보관한 무작위 토큰의 해시를 함께 저장하고, 삭제할 때 `delete_comment` 함수가 토큰을 대조합니다.
- 답글은 최상위 의견에만 한 단계로 달 수 있습니다.
- 입장 암호는 화면을 가리는 가벼운 장치입니다. 페이지 소스를 열면 우회할 수 있으므로, 공개되면 곤란한 내용은 페이지에 넣지 않습니다.
