# 2027 임금·단체교섭 요구안 해설 · 연구소 공유본

녹색전환연구소노동조합이 연구소(사측)와 함께 보기 위해 만든 요구안 해설 페이지입니다. 조합원 공유본(`imdanhyup-2027`)과 저장소, 주소, 의견 저장소를 모두 분리했습니다.

## 구성

- `index.html`: 배포되는 페이지(빌드 결과물)입니다. GitHub Pages가 이 파일을 그대로 제공합니다.
- `src/gdoc.html`: 구글 문서 「녹조_2027년 임금·단체교섭 요구안 해설_사측공유본」의 HTML 내보내기입니다.
- `src/current-rules.html`: 현행 규정 7종(기본협약, 2026년 임금협약, 취업규칙, 운영실무규정, 고충처리규정, 회계실무규정, 퇴직연금규약)의 원문입니다.
- `src/laws.json`: 요구안이 인용한 법령 조문 113개의 현행 원문입니다. 조문 번호에 마우스를 올리면 보이는 미리보기에 씁니다.
- `tools/fetch_laws.py`: 위 법령 원문을 국가법령정보센터에서 다시 가져옵니다.
- `tools/parse_doc.py`: 구글 문서를 조문 단위 데이터로 바꿉니다.
- `tools/build.py`: 데이터와 `tools/style.css`, `tools/app.js`를 합쳐 `index.html`을 만듭니다.

## 다시 만들기

구글 문서를 고친 뒤에는 문서를 HTML로 내보내 `src/gdoc.html`을 바꾸고 아래 명령을 실행합니다. 입장 암호는 환경변수로 넘기며, 페이지에는 SHA-256 해시만 들어갑니다.

```sh
pip install beautifulsoup4 lxml
GATE_PASSWORD='전달할 암호' python3 tools/build.py
# 암호를 바꾸지 않을 때는 지금 페이지의 해시를 그대로 넘겨도 됩니다
GATE_HASH='a946858f…' python3 tools/build.py
# 새로 인용한 법령 조문이 있다고 나오면 원문을 받은 뒤 다시 빌드합니다
python3 tools/fetch_laws.py && GATE_PASSWORD='전달할 암호' python3 tools/build.py
```

부록 D(노사 공유 자료)는 연구소 공유본에 싣지 않습니다. `src/gdoc.html`에서도 잘라 냈고, 빌드할 때 다시 걸러 냅니다.

## 의견 저장소

Supabase 프로젝트 `imdanhyup-2027-share`(서울 리전)의 `comments` 테이블을 씁니다.

- 누구나 읽고 쓸 수 있지만, 삭제는 의견을 남긴 브라우저만 할 수 있습니다. 등록할 때 브라우저에 보관한 무작위 토큰의 해시를 함께 저장하고, 삭제할 때 `delete_comment` 함수가 토큰을 대조합니다.
- 답글은 최상위 의견에만 한 단계로 달 수 있습니다.
- 입장 암호는 화면을 가리는 가벼운 장치입니다. 페이지 소스를 열면 우회할 수 있으므로, 공개되면 곤란한 내용은 페이지에 넣지 않습니다.

## 실무교섭 기록

노사 간사가 실무교섭 중에 각자 노트북에서 함께 적는 회의기록 공간입니다. 확정된 회의록은 이 기록을 바탕으로 사후 확인을 거쳐 구글 문서(회차별 탭)에 작성합니다.

- 회차(`rounds`): 본교섭·실무교섭과 차수, 일시, 장소, 참석, 요약, 향후일정, 붙임을 둡니다. 머리의 회차 선택에서 만들고 고릅니다.
- 기록(`minutes`): 조문별 기록(`kind='art'`, 회차·조문마다 하나)과 기타 안건(`kind='agenda'`)을 함께 둡니다. 칸은 노측 입장, 사측 입장, 논의경과, 회의결과, 처리 상태입니다.
- 처리 상태: 원안합의, 수정합의, 추후논의, 참여형 회부, 본교섭 회부, 쟁점. 조문 머리와 목차에는 가장 최근 회차의 상태가 표시됩니다.
- 쓰기: 간사 암호(노측·사측 각각)를 서버 함수(`art_set`, `agenda_*`, `round_*`)가 확인한 뒤에만 이루어집니다. 암호 해시는 `secretary_keys` 테이블에 있으며 브라우저에서는 읽을 수 없습니다. 칸 단위로 저장하므로 두 간사가 다른 칸을 동시에 고쳐도 서로 덮어쓰지 않습니다.
- 실시간: Supabase Realtime으로 상대 화면에 곧바로 반영하고, 상대 간사가 입력 중인 칸에는 표시가 붙습니다. 연결이 끊기면 30초마다 다시 불러옵니다.
- 회의록 초안: 실무교섭 기록 탭에서 구글 문서 회의록 양식(개요·요약·회의결과·향후일정·붙임)에 맞춘 초안을 복사하거나 Markdown으로 내려받습니다.

간사 암호를 바꾸려면 Supabase SQL 편집기에서 다음을 실행합니다.

```sql
update public.secretary_keys set key_hash = encode(sha256(convert_to('새 암호','UTF8')),'hex') where side = 'u'; -- 사측은 'i'
```

예전의 조문별 의견란(`comments` 테이블)은 화면에서 내렸고 테이블은 그대로 두었습니다.
